# 🏦 Bank Customer Churn Analysis

![Python](https://img.shields.io/badge/Python-3.8+-blue)
![Status](https://img.shields.io/badge/Status-Complete-green)

## 📌 Overview
Analyzed 10,000 bank customer records to identify churn drivers 
and built a machine learning model to predict which customers 
are likely to leave the bank.

## 📊 Key Findings
- 1 in 5 customers churned
- German customers churn at a disproportionately high rate
- Customers aged 45–50 are the highest risk group
- Inactive members churn almost twice as much as active members
- Higher balance customers are more likely to leave

## 🤖 Model
- Algorithm: Decision Tree Classifier
- Accuracy: 78.2%

## 🛠️ Tools Used
- Python, Pandas, Seaborn, Matplotlib, Scikit-learn
